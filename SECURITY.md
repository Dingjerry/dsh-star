# Security policy

Please do not report vulnerabilities, API keys, access tokens, Harness
credentials, or private logs in a public issue.

For now, open a private GitHub security advisory for this repository. If that
option is unavailable, contact the maintainer through the email listed on the
GitHub profile and include only the minimum reproducible details.

Before sharing logs, remove:

- API keys and bearer tokens
- Harness profiles, cookies, and credentials
- Personal file paths and private prompts
- Local network addresses that are not needed to reproduce the issue
